# 功能补全：成就系统 / 新手引导（2026-11-25）

## 一、成就系统（`src/achv.js` + `src/ui.js` + `src/select.js`）
- 纯前端推导，不需要额外行为打点：星数、城堡等级、英雄进化阶、盟友数、装备数、Raid 通关数、累计签到天数。
- 10 条成就（宝石奖励 10~50）：首战告捷 / 星光收集者(30★) / 群星璀璨(90★) / 坚城(城堡5) / 铁壁要塞(城堡10) / 进阶骑士(英雄3阶) / 结盟(3 盟友) / 全副武装(5 装备) / 屠龙者(3 Raid Boss) / 勤勉(累计签到 7 天)。
- 入口：选关页顶栏齿轮左侧的星星按钮，可领数量走小红点（与齿轮互不干扰，齿轮仍由 main 全局接管）。
- 面板：名称 + 描述 + 进度条 + 当前/目标 + 宝石奖励，达成后「领取」按钮直接到账并 `achvClaims[id]=true` 防重复。
- 签到次数新增 `Player.signTotal`（`Daily.sign()` 内累加并落存档）。

## 二、新手引导（`src/tutorial.js`）
- 仅**新档**触发（`load()` 时 `_fresh` → `tutorialStep=1`），老档 `tutorialStep=0` 不打扰。
- 4 步：①点 1-1 的 Battle → ②战斗中点技能 → ③城墙血条见底即输 → ④顶栏星星/里程碑能领奖励。
- 表现：四块压暗矩形拼出高亮洞（不用 `clearRect`，避免把场景擦成透明），高亮区呼吸描边 + 说明气泡 + 跳过/下一步。
- 交互：高亮区点击放行给场景（玩家可以真的点 Battle 开始战斗），气泡外其余区域吞掉防误触；场景切换自动推进（进战斗 1→2，提前回选关 2/3→4），跳过或走完写回 `tutorialStep=0`。
- `?tab / ?auto / ?stage` 验收入口自动关闭引导。
